# First Choice Result Portal Orientation Package

This package is the handover orientation for First Choice Standard Schools. It follows the complete journey:

**Registration → academic setup → teacher work → review → report card.**

## The three layers

1. **Reference manuals:** `ADMIN-MANUAL.md` and `TEACHER-MANUAL.md`.
2. **Training slides/videos:** `ORIENTATION-SLIDES-SCRIPT.md`. Each topic can be recorded as a short screen video.
3. **In-system checklists:** `ORIENTATION-CHECKLISTS.md`. These can be shown at the beginning of each training session or converted into help prompts.

## Access rule

Teachers can carry out the normal academic work: access their result workspace, work with the available student/class records, enter and review academic data, and submit or manage result entries permitted by the school workflow.

Teachers cannot:

- open Settings;
- print individual or multiple report cards.

Administrators can do all teacher operations, open Settings, manage the academic configuration and staff access, review results, and print report cards.

The portal now enforces the report-card printing restriction in both the visible controls and the print actions. Settings were already restricted to management accounts.

## Recommended delivery

- Give each user the relevant PDF manual.
- Conduct one live orientation using the slide script.
- Record one short video per major task, ideally 3–7 minutes each.
- Keep the checklists beside the computer during the first result cycle.
- Use a practice session or approved sample records before live school data entry.
